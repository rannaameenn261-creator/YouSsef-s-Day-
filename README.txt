YouSsef Baby Website — GitHub Pages

IMPORTANT:
- Keep index.html at the top level.
- Keep style.css and script.js at the top level.
- Keep the assets folder beside them.
- The music file is already included as:
  assets/youssef-song.mp3

GitHub Pages:
1. Upload/replace all files in your repository.
2. Make sure assets/youssef-song.mp3 is inside the assets folder.
3. Wait a few minutes for GitHub Pages to publish.
4. Open the site and press the music button (♪) at the top.

The music is intentionally started by a button click because browsers generally block automatic audio playback.
